# Upgrade 2.0C.3

Added `src/news.js` and news interface styles, live geographic feed fetching, geographic category clustering, selectable news sprites, article drawer and refresh controls. Preserves all the previous independent map layers. The new version references the original WorldPulse news JSON using a read-only public URL and offers an optional static local fallback (`data/news.json`).

No GitHub Actions workflows are replaced or edited.
